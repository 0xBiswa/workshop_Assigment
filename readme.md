# 🚀 NIT Nagaland Coding Club - First-Year Assignment 01

Welcome to your first official open-source assignment with the **NIT Nagaland Coding Club**! 

This repository is designed to help first-year students practice basic C programming while learning the standard Git and GitHub workflow (Forking and Pull Requests).

## 📝 The Coding Assignment

Choose **ONE** of the following basic logic problems and implement it in a C program. Your file must include a `main()` function to test your logic.

*   **Option A: Prime Number Checker**
    *   Write a program that takes an integer as input and prints whether it is a prime number or not.
    *   *Example function:* `int is_prime(int num);`
*   **Option B: Factorial Calculator**
    *   Write a program that takes a positive integer and calculates its factorial.
    *   *Example function:* `int factorial(int num);`
*   **Option C: Fibonacci Sequence**
    *   Write a program that prints the first *n* terms of the Fibonacci sequence based on user input.
    *   *Example function:* `void print_fibonacci(int n);`

### 📂 File Naming Convention
Name your source code file using your first and last name in lowercase, separated by an underscore.
*   ✅ **Correct Example:** `meraj_alam.c`
*   ❌ **Incorrect Example:** `code.c`, `MyAssignment.c`

## 🛠️ How to Submit Your Assignment

We use the standard **Fork and Pull Request** workflow. Follow these steps to submit your code:

1. **Fork this repository:** Click the "Fork" button at the top right of this page to create your own copy.
2. **Clone your fork:** Download your copied repository to your computer.
   ```bash
   git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git
   cd REPOSITORY-NAME
   ```
3. **Add your code:** Create your C file (e.g., `firstname_lastname.c`) in the folder and write your code.
4. **Commit your changes:** Save your work to Git.
   ```bash
   git add firstname_lastname.c
   git commit -m "Added [Your Name] assignment"
   ```
5. **Push to your fork:** Upload the code back to your GitHub account.
   ```bash
   git push origin main
   ```
6. **Create a Pull Request (PR):** Go to your forked repository on GitHub and click **"Compare & pull request"**. Add a brief description of which option you chose, and submit the PR!
